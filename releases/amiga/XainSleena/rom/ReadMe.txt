XAIN'D SLEENA - the ROMs
========================

Put the arcade ROMs into this drawer (XainSleena/rom). They are not
included: you need your own copy of the MAME set "xsleena"
(Xain'd Sleena, World), either

  - the file xsleena.zip, or
  - a drawer xsleena with the files (p0-0.ic15 ... pz-0.113).

The bootlegs (xsleenab, xsleenaba) and the Japanese version are not
supported. The MCU code pz-0.113 is needed. Another place for the ROMs:
the Tool Type ROMPATH= (see XainSleena/doc/XainSleena_en.txt).


Tu wloz ROM-y automatu (XainSleena/rom). Nie ma ich w paczce: potrzebny
jest wlasny zestaw MAME "xsleena" (Xain'd Sleena, World) - plik
xsleena.zip albo szuflada xsleena z plikami (p0-0.ic15 ... pz-0.113).
Wersje bootleg (xsleenab, xsleenaba) i japonska nie sa obslugiwane.
Potrzebny jest kod MCU pz-0.113. Inne miejsce na ROM-y: Tool Type
ROMPATH= (opis w XainSleena/doc/XainSleena.txt).
