XAIN'D SLEENA - releases (fixes and additions)
==============================================

The release number is shown on the game's start screen (RELEASE x.y.z,
where the credit count was; with START=ARCADE the screen is as on the
arcade) and in the Shell: Version XainSleena. When reporting a bug, give the release number - it
tells whether the bug has already been fixed in a newer one.

Reporting a bug: when the game freezes or something odd
happens, press F10 (since 0.9.10: the numbered files
RAM:XainSleena-dumpN.bin / .txt / .ppm and RAM:XainSleena-stateN.bin).
Copy them before switching the Amiga off (RAM: is lost) and send them
with the release number. The authors replay the last seconds of play
and see exactly what happened on the Amiga.


RELEASE 0.9.14  (17.10.2026)
----------------------------

Changes:
- Tile rows of one colour (e.g. the black star background of the flying
  stages) are filled with long words: drawing about 0.3-0.7 ms shorter.


RELEASE 0.9.13  (17.10.2026)
----------------------------

Changes:
- The picture is drawn only where it can have changed (bands with
  sprites, changed background or text); a colour change needs no new
  drawing. On your F10 replays (SCALE=1, 100 MHz): drawing about 15-16
  -> 11-13 ms, 26-30 -> 34-39 pictures per second; less gain while the
  background scrolls (all of it changes).


RELEASE 0.9.12  (17.10.2026)
----------------------------

Fixes:
- After the base is destroyed (COUNT DOWN, jump into the ship) up on the
  joystick did not jump (only Space did), so the mission could not be
  finished properly. The game is in another state in this phase, which
  the port did not take as "on foot". Fixed (the up arrow key too).


RELEASE 0.9.11  (17.10.2026)
----------------------------

Additions:
- Option TEST (for checking stages): on foot the DAMAGE GAGE bar does not
  go down, infinite lives. In the flying stages a hit still destroys the
  ship, but the game goes on. Put TEST last in the Tool Types (or
  DIFFICULTY=NODAMAGE - only no damage).


RELEASE 0.9.10  (17.10.2026)
----------------------------

Changes:
- F10 now saves a full set for bug reports, numbered (each press makes new
  files, nothing is overwritten):
    RAM:XainSleena-dumpN.bin   a replay of the last 9-18 seconds of play
    RAM:XainSleena-stateN.bin  the state of the arcade board at the press
    RAM:XainSleena-dumpN.txt   description: stage, options, keyboard, joystick
    RAM:XainSleena-dumpN.ppm   the picture on the screen
  The screen flashes when it is saved. The files are lost when the Amiga
  is switched off - copy them or report at once.


RELEASE 0.9.9  (17.10.2026)
---------------------------

Fixes:
- After losing a life (and on other colour changes) parts of the screen,
  e.g. a flat sky, stayed black or in the old colour until an object
  moved through them (0.9.7, 0.9.8). Cause: a too weak checksum of the
  picture parts. Fixed.
- The full screen is redrawn whole when something covered it (another
  window, a system requester), and also every few seconds.


RELEASE 0.9.8  (17.10.2026)
---------------------------

Changes:
- A change of the game's colours (the game does it very often, e.g. a
  flashing background) no longer sends the whole picture to the card,
  only the parts that really look different. Heaviest scene at 100 MHz:
  full screen SCALE=2 29-30 pictures per second (0.9.7: about 17-20),
  SCALE=1 31-32.
- LAGLOG (diagnostic option): a summary of every 10 seconds of play in
  RAM:XainSleena-lag.txt, and on longer slowdowns the machine state
  (RAM:XainSleena-lagN.bin) for bug reports.


RELEASE 0.9.7  (17.10.2026)
---------------------------

Changes:
- Faster picture output with many enemies and scrolling: the picture is
  built in bands of 8 lines, the changed parts are converted to the card's
  colours and sent at once. In the heaviest scene (68060/100 MHz, full
  screen) 28-29 pictures per second instead of 20-21; in a window with
  SCALE=2 17 instead of 14-15. The game (logic) still runs at the full
  arcade speed.
- Note: at a 55 MHz clock the game slows down in heavy scenes (the
  emulation cannot keep up); a 100 MHz clock is recommended.


RELEASE 0.9.6  (15.10.2026)
---------------------------

Fixes:
- Jumping sideways with up (keyboard, and the joystick with CONTROL=JOY1):
  the game takes the jump direction only at take-off, so left/right
  pressed a moment after up gave a straight jump. The jump now waits up
  to 3 frames (about 1/20 s) for a side direction. The direction cannot
  be changed in the air - as on the arcade.


RELEASE 0.9.5  (12.10.2026)
---------------------------

Additions:
- Difficulty VERY EASY (DIFFICULTY=VERYEASY): on foot, hits take a quarter as much from
  the DAMAGE GAGE bar (EASY: half as much).


RELEASE 0.9.4  (12.10.2026)
---------------------------

Changes:
- Keyboard as the joystick: up on foot = jump, in the ship it only moves
  up; Y = extra weapon in the ship. Z = shoot, X still works as fire 2
  (spare).


RELEASE 0.9.3  (12.10.2026)
---------------------------

Changes:
- Keyboard following the common standard: cursor keys = move, Z = fire 1
  (shoot), X = fire 2 (jump / extra weapon), P = pause. The alternatives
  Ctrl, Alt and Space are gone.
  Space stays as the joystick's second button with CONTROL=JOY1.


RELEASE 0.9.2  (12.10.2026)
---------------------------

Additions:
- The release number on the start screen (RELEASE 0.9.2 instead of
  CREDIT 2) and in Version.
- CONTROL=JOY1 description: the joystick's second button is Space.
- Separate descriptions for the Amiga and the PC version (the Amiga
  package has only the Amiga settings).
- This file: the fixes and additions of every release, packed with
  the game.


RELEASE 0.9  (12.10.2026) - first release
-----------------------------------------

Game:
- Emulation of the Xain'd Sleena arcade board (3x 6809, 68705 MCU,
  2x YM2203) on the Amiga 1200 with a 68060 and a graphics card.
- START=EASY (default): coins inserted automatically, joystick left /
  right = 1 / 2 player game, after the last life PRESS FIRE TO
  CONTINUE (fire = go on). START=ARCADE: as the arcade.
- CONTROL=JOY1 (default): one button joystick, up = jump on foot, in
  the flying stages Space = extra weapon. CONTROL=JOY2: the second
  joystick / pad button. CONTROL=KEYBOARD.
- DIFFICULTY=EASY: on foot, hits take half as much from the DAMAGE
  GAGE bar (not in the original).
- LIVES=3|4|6|INF.
- Icon: full screen (SCREEN=FULL), all options as Tool Types.

Diagnostics:
- F10: saves the whole state of the arcade board to
  RAM:XainSleena-state.bin for bug analysis. See above.
- Watchdog: when the game draws no frame for 3 s, the program's state
  goes to RAM:XainSleena-hang.txt.

Fixes (against the test builds):
- The game froze now and then (picture stands still, music plays,
  nothing works): a race of the arcade's two CPUs for a shared
  synchronisation byte. Found thanks to an F10 dump from an A1200.
- In the flying stages there were no enemies after a death and the
  stage ended by itself: the PRESS FIRE TO CONTINUE text change altered
  the ROM checksum, and with a wrong sum the game switches on its own
  protection. The sum is kept now.
- Jumping with joystick up (JOY1) did not work on foot.
